### Field mapping for agent log queries

| Purpose | Field |
|---|---|
| Service name | `resource.service.name` |
| Message / body | `body` |
| Severity text | `severity.text` (`info`, `warn`, `error`, `debug`) |
| Severity number | `severity.number` (9=INFO, 13=WARN, 17=ERROR) |
| Timestamp | `@timestamp` |
| Trace correlation | `traceId`, `spanId` |
| HTTP method/status | `attributes.http.request.method`, `attributes.http.response.status_code` |
| Custom attrs | `attributes.<key>` |

### Compliance notes

- `action-api` must **never return** flag values to the agent caller (Hard Rule 1)
